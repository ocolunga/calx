# calx

Calendar Expanded - A command-line tool for displaying calendar information with terminal graphics.

## Features

- ISO week number
- Week number (Monday/Sunday start)
- Day of year, biweek number
- Beautiful terminal formatting using Rich

## Installation

```bash
pip install calx
```

Or with uv:

```bash
uv pip install calx
```

## Usage

```bash
calx
```

## Development

```bash
uv sync --group dev
uv run calx --help
```
